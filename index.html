Owned Gift Link File Checker

Upload a text, CSV, or log file containing gift links or codes you already possess, or paste them manually. This tool normalizes your input, validates supported formats locally, removes duplicates, processes rows in parallel, supports large-file streaming, and can optionally notify a webhook with the format-valid entries from your own file or list.

Safety boundary: This page does not generate, brute-force, discover, or probe random gift links, and it does not call Discord APIs. It only processes the entries you manually provide by file upload or text input.

What this tool does and does not do

Does: normalize uploaded or pasted entries, validate format, deduplicate, process in parallel local batches, stream large files, export results, and optionally post your provided entries to a webhook.

Does not: generate random codes, probe external services, verify redemption status, attempt claims, or discover links you did not already supply.
